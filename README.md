# CA3: Sarcasm Detection in News Headlines

## Project Overview
This project explores sarcasm detection in news headlines using Natural Language Processing (NLP). It includes model development, performance evaluation, subgroup auditing, explainability analysis, and a simple website interface.

## Repository Contents
- `CA3_Sarcasm_Detection_Final.ipynb` — Complete Google Colab notebook containing the project workflow.
- `sarcasm_detector_website.html` — Website interface for the sarcasm detection project.
- `figures/` — Exported figures and visualizations.
- `Sarcasm_Detection_Model_Card.pdf` — Model card documenting the model, intended use, performance, limitations, and recommendations.
- `presentation.pptx` — Project presentation.

## How to Run the Notebook
1. Download `CA3_Sarcasm_Detection_Final.ipynb` or open it from this repository.
2. Upload the notebook to [Google Colab](https://colab.research.google.com/).
3. Install any required dependencies listed in the notebook.
4. Upload or configure access to the dataset as specified in the notebook.
5. Run the cells in order from top to bottom.

## How to Open the Website
1. Download `sarcasm_detector_website.html` from this repository.
2. Open the downloaded file in a web browser.

Note: If the website requires a running backend or model server, start that service as described in the project code. Opening the HTML file alone may not enable live predictions.

## Project Outputs
The repository contains the notebook, website, exported figures, model card, and presentation for review and reproducibility.
